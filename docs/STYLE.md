# ЭнергоСфера — руководство по стилю

Единый вид всех модулей. Любой новый экран собирается по этим правилам и **только
из готовых элементов** `apps/web/src/ui/kit.tsx`. Если элемента не хватает —
сначала добавить его в набор (и сюда), потом использовать.

Ориентир: дашборд из четырёх цветных колонок, свёрнутые модули — вертикальные
полосы слева, меню открытого модуля — цветная колонка, контент — на тёплом
светлом фоне справа. Спокойно, крупно, много воздуха, без лишних рамок.

## 1. Принципы

1. **Без модальных окон.** Всё — на странице: раскрывающиеся карточки, формы над
   списком, подтверждение удаления — второй кнопкой «Удалить?» на месте.
2. **Одна высота элементов управления — 44 px** (`--control-h`): кнопки, поля,
   выпадающие списки, кнопки-иконки (44×44). Не уменьшать «для компактности».
3. **Цвет модуля — только через переменные** `--tint`, `--accent`,
   `--accent-strong`. Никаких своих HEX в стилях модуля, кроме смысловых (ниже).
4. **Смысловые цвета** (ошибка, предупреждение, норма) — общие токены
   `--danger`, `--warn`, `--ok`. Их не перекрашивать в цвет модуля.
5. **Десктоп в приоритете, телефон не ломать.** Порог — `max-width: 900px`:
   сетки в одну колонку, меню модуля — горизонтальная лента.
6. **Текст по-русски, по-человечески.** Кнопка — глагол («Добавить документ»,
   «Сохранить план»), ошибка — что случилось и что делать
   («Для роли «Монтёр» выберите РЭС»). Без «Ошибка 403» и англицизмов.
7. **Анимации короткие и по делу:** переходы `.15s`, перестройка колонок
   `--morph` (620 мс, `--ease`). Без бесконечных анимаций. `prefers-reduced-motion`
   уважается глобально (tokens.css).

8. **Цветные блоки — только заливкой.** Блок с разделом (карточка потребителя, анкета акта
   и т. п.) целиком залит своим оттенком (`.block`, `.block--1…6` или по кругу в `.blocks`,
   ui.css), заголовок — цветная плашка с белым текстом (`.block__title`). **Никогда:**
   цветные полосы слева/сверху блока (`border-left`/`border-top` цветом), подчёркивания
   строк внутри блока. Решение владельца 24.11.2026 — «не хочу видеть никогда».

## 3. Каркас экрана

```
┌ TopBar 64px: сфера + ЭНЕРГОСФЕРА ······ Сочинские электрические сети │ 🔔 │ (профиль) ┐
├─┬─┬─┬──────────────┬──────────────────────────────────────────────────┤
│п│п│п│ ← Все разделы │ ЭнергоСфера / Модуль          (крошки)            │
│о│о│о│  [иллюстрация]│ Заголовок страницы 34px       [действия справа]   │
│л│л│л│  Название     │ подзаголовок — что здесь и зачем                  │
│о│о│о│  • пункт меню │ ┌ карточка ┐ ┌ карточка ┐                         │
│с│с│с│  • пункт      │ └──────────┘ └──────────┘                         │
│а│а│а│  ─────────    │                                                   │
│ │ │ │  Рабочее простр.                                                  │
└─┴─┴─┴──────────────┴──────────────────────────────────────────────────┘
 64px полосы   300px меню           контент: отступы 30px / 44px, max-width 1320
```

- Пункт меню модуля = одна страница. Меню и иллюстрация — в `registry.tsx`
  (`menu: [{ id, title, icon, perm?, about }]`), `about` — подзаголовок страницы.
- Каждая страница начинается с `PageHeader` (крошки, заголовок, подзаголовок,
  действия). Основное действие страницы — справа в шапке.
- Маршрут хранится в адресе: `#/<модуль>/<страница>`.

## 4. Элементы (`ui/kit.tsx`) и когда какой

| Элемент | Когда |
|---|---|
| `Button variant="primary"` | одно главное действие на экране (заливка `--accent` модуля) |
| `Button` (secondary, по умолчанию) | обычные действия: белая, графитовая рамка 1.5px |
| `Button variant="ghost"` | второстепенное в строках: «Доп. права», иконка-удаление |
| `Button variant="danger"` | только подтверждение необратимого («Удалить?») |
| `Button icon={<Icon…/>}` без текста | кнопка-иконка 44×44, обязательно `title` и `aria-label` |
| `Input`, `TextArea`, `Select` | поля; подпись — через `Field label hint` |
| `Checkbox`, `Switch` | флажок (отметки, матрицы) / переключатель (вкл-выкл доступа) |
| `Card title aside` | любой блок контента; `card--flush` — для таблиц во всю ширину |
| `PageHeader` | шапка каждой страницы |
| `Badge tone` | короткий статус: `warn` «Ожидает роли», `accent` «Суперадмин» |
| `Progress value total` | доля выполненного |
| `Empty image title text` | пустое состояние: что здесь будет и что сделать |
| `useToast()` | итог действия: «Сохранено» (3 с) / текст ошибки (6 с, красный) |
| `.tabs` + `.tab` + `.tab__count` | переключение видов на странице (Все / Ожидают роли …) |
| `.search` + `Input` | поиск над списком, иконка лупы внутри |
| `.table` в `Card card--flush` | таблицы: шапка капсом 12px, строки 14px, hover |

Иконки — `ui/icons.tsx`: инлайн SVG 24×24, линия 1.8, скруглённые концы,
`currentColor`. Новые иконки рисуются в том же стиле и добавляются туда же.

## 5. Узоры

- **Раскрывающаяся карточка** (направление плана, техкарта): шапка-кнопка во всю
  ширину, справа счётчик и шеврон (поворот 180° при раскрытии), раскрытая
  карточка в сетке занимает всю строку (`grid-column: 1 / -1`).
- **Правка на месте:** кнопка «Редактировать» в шапке → поля прямо в карточках →
  «Отменить» / «Сохранить …» в шапке. Черновик — копия данных; отмена его
  выбрасывает.
- **Удаление:** кнопка-иконка корзины → на её месте `danger` «Удалить?» → второй
  клик удаляет. Никаких `confirm()`.
- **Форма добавления** — карточка над списком (`doc-add`), сетка полей
  `auto-fill, minmax(240px, 1fr)`, кнопки «Отменить» / «Добавить» справа внизу.
- **Номера и коды** (С-01, № 49 от …) — маленький «чип» цвета модуля:
  `color: var(--accent-strong)`, фон `color-mix(var(--accent) 35–40%, #fff)`.
- **Сетки карточек:** `repeat(auto-fill, minmax(320–360px, 1fr))`, зазор 16px.
- **Загрузка:** текст «Загрузка…» (`.muted`); вход — сфера, крутящаяся 3 раза.

## 6. Чужой код во фрейме (модули 01 и 04)

Готовые программы, которые переносятся как есть (анализатор), открываются во
фрейме того же сайта, а вид подтягивается слоем `es-theme.css` поверх их стилей:
шрифт, кнопки 44px с графитовой рамкой, сегменты как вкладки Сферы, карточки 16px,
палитра модуля. Свои шапка и вкладки программы скрываются — их заменяют
`PageHeader` и меню модуля (связь — `postMessage`, см. `es-bridge.js`).
Так же устроен модуль 04 (TP_Approval): `apps/tp-web/public/tp-theme.css` и
`es-tp-bridge.js`. Правка вида такой программы — только в слое темы, её
импортированный код не трогаем (его перезапишет следующий импорт).

## 7. Проверка перед сдачей экрана

- [ ] Собран из `kit.tsx`, нет своих кнопок/полей и своих HEX (кроме смысловых).
- [ ] Все кнопки 44px; у кнопок-иконок есть `title` и `aria-label`.
- [ ] Нет модальных окон, `alert`/`confirm`.
- [ ] Есть `PageHeader`, пустое состояние и «Загрузка…».
- [ ] Ошибки и итоги — тостом, понятным текстом.
- [ ] Проверено на ширине 1600 и 390 px (скриншот глазами).
- [ ] Действия, которые нельзя всем, скрыты по праву (`can('…')`) и закрыты на
      сервере (`requirePermission`).
