# ЭнергоСфера

Единая рабочая платформа Сочинских электрических сетей: анализ потребления,
поиск потребителя, инструкция начальника РИРУ и акты ТП — в одном приложении
с одной базой. Вход — через платформенный Keycloak, доступы — по ролям и РЭС.

Подробности для разработки — в [AGENTS.md](AGENTS.md).
